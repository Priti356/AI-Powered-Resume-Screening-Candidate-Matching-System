
# AI-Powered Resume Screening & Candidate Matching System

## Project Overview
The AI-Powered Resume Screening & Candidate Matching System is a Python-based application designed to simplify the recruitment process by extracting information from resumes and helping recruiters identify suitable candidates.

## Features
- Upload PDF and DOCX resumes.
- Extract text from resumes.
- Process resume information using Python.
- Support automated resume screening.
- Help compare candidate skills with job requirements.

## Technologies Used
- Python
- Flask
- PyMuPDF
- python-docx
- Pandas
- Scikit-learn

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Priti356/AI-Powered-Resume-Screening-Candidate-Matching-System.git
```

2. Open the project folder:

```bash
cd AI-Powered-Resume-Screening-Candidate-Matching-System
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```
